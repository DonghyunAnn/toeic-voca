# CSV 대조 정합성 검토

날짜: 2026-08-27
대조 자료: `ETS TOEIC VOCA.csv` (3,155행, 예문 없음)

## 요약

블로그 크롤링 결과는 **정확하지만 절반이다.** 수집한 1,566개 표제어 중
1,549개(98.9%)가 CSV와 일치했고, 나머지 17개도 대부분 블로그 원문의 오타였다.

문제는 누락이다. 블로그는 각 DAY의 단어를 **절반만 게시한다.**

| | 단어 수 |
|---|---|
| CSV | 3,155 |
| 블로그 크롤링 | 1,591 |
| CSV에만 있음 | 1,533 |

DAY26(전치사)만 예외로 56 대 56으로 일치했다. 나머지 DAY는 모두 CSV의 절반 수준이다.

## 누락 원인 확인

블로그 쪽 수집 실패가 아니라는 것을 세 가지로 확인했다.

1. **포스트 목록은 완전하다.** `itemCount=20`으로 페이지를 나눠 받으면
   20 + 10 + 0으로 정확히 30개가 나온다. DAY01~30에 빠짐도 중복도 없다.
   (`itemCount`의 상한은 30이다.)
2. **본문에 이미지가 없다.** 단어가 이미지에 갇혀 있을 가능성을 확인했으나
   본문 이미지 수는 0이다.
3. **본문이 잘리지도 않았다.** DAY01의 마지막 줄은 `stroll`의 연어로 정상 종료한다.
   분류 실패한 줄도 전체 5줄뿐이다.

즉 블로그가 애초에 절반만 올린 것이다. 제목의 "예문 … + 뜻 있음"과 맞아떨어진다.
예문을 붙일 수 있는 단어만 골라 게시한 것으로 보인다.

## 블로그 원문 오류

CSV와 대조해 특정한 것들이다.

**뜻 오타 (9건)**

| 단어 | 블로그 | 올바른 값 |
|---|---|---|
| defect | 결합 | 결함 |
| summarize | 요악하다 | 요약하다 |
| prop | 받치디 | 받치다 |
| unprecedented | 전례없은 | 전례 없는 |
| likely | ~할 것 같은은 | ~할 것 같은 |
| debut | 정돈하다 | 데뷔하다 |

**표제어 오타 (표제어가 다른 단어로 적힘)**

| 블로그 표기 | 실제 단어 | 근거 |
|---|---|---|
| access (DAY17) | excess | 뜻이 "초과, 초과량, 과잉" |
| perspective (DAY22) | prospective | 뜻이 "장래의, 가망이 있는" |
| plummer | plumber | 예문이 "The plumber can…" |
| complementary | complimentary | 예문이 "our complimentary…" |
| oversea | oversee | 예문이 "responsible for overseeing" |
| sizeable | sizable | 예문이 "a sizable amount" |
| crank | crack | 예문이 "several small cracks" |
| inconveniencet | inconvenience | 예문이 "for the inconvenience" |

**품사 오류 (8건)** — `annual`을 `v.`로, `misleading`을 `n.`으로 적는 등.

## CSV 쪽 오류

CSV도 완전하지는 않다.

| 항목 | 문제 |
|---|---|
| `appropriated` | `appropriate`의 오타. 뜻은 "적당한, 적절한"으로 맞다. |
| `credit card ` | 뜻이 "v. 입금하다"로 붙어있다. `credit`의 뜻이다. |
| `eco-friendly` | 없다. 블로그에만 있다. |
| `resume` | 동사 "재개하다"만 있다. 명사 "이력서"가 빠졌다. |

## 병합

`merge.py`가 두 자료를 합친다.

- 뜻과 품사는 **CSV**를 따른다 (오류가 적다)
- 예문과 연어는 **블로그**에서 가져온다 (CSV에는 없다)
- 위 오타 표를 손으로 교정해 어긋난 표기를 잇는다
- CSV에 대응이 없는 블로그 단어 4건은 버리지 않고 해당 DAY에 덧붙인다

퍼지 매칭(`difflib`)도 시도했으나 `oversea`를 `overseas`로, `credit`을 `creditor`로
잘못 이었다. 17건 규모라면 손으로 적은 교정표가 안전하고 검토도 가능하다.

**결과: 3,159단어, 그중 1,585개(50.2%)에 예문.**

단어 id는 `d{DAY}-{표제어}` 형식으로 바꿨다. 순번 기반(`d01-001`)은 데이터를
다시 만들 때 학습 기록이 엉뚱한 단어에 붙는다.

## 앱 반영

예문 없는 단어가 절반이므로 설정에 **출제 범위**를 두었다.
"전체 단어"와 "예문 있는 것만"을 고를 수 있고, 홈 통계·DAY 진행률·플래시카드·퀴즈에
모두 적용된다.
